# Notebooks

Jupyter notebooks for experimentation, prototyping, and analysis.

## Available Notebooks

### `catogorise_the_article.ipynb`
Experiments with topic classification methods:
- LDA topic modeling
- Keyword-based classification
- Pre-trained topic models
- TF-IDF clustering

### `test_topic.ipynb`
Testing and validation of topic classification approaches.

## Usage

These notebooks are for exploration and should not be used in production. Production code should be in the `/src` directory.
